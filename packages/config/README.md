# packages/config

Shared ESLint/TypeScript/Prettier configuration so every app enforces the same standard (strict TS, accessibility lint rules). **Deliberately left empty by `FOUND-015`**, not populated: `apps/storefront` already ships its own sophisticated `eslint.config.mjs` from the official Next.js starter, and `apps/server` has no ESLint config upstream at all — inventing a shared preset before there is real backend plugin code to lint against would be speculative. Root-level formatting is governed by the repo-root `.prettierrc`/`.prettierignore` (deliberately scoped away from `apps/*`'s own vendored conventions — see `docs/implementation/dependency-register.md` "Known gap"). Revisit once real backend plugin code lands (Phase 1C, `lipek-security` onward) and a genuine shared-preset need appears.
