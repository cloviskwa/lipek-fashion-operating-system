# _reference/legacy-prototype

The original static-content Next.js 15 marketing-site prototype from the `LIPEK FASHION` repository, kept here **for reference only** during `FOUND-020` (porting reusable design tokens, route/IA structure, and the SEO/JSON-LD pattern into the real `apps/storefront`, which is bootstrapped fresh from the official Vendure Next.js starter in `FOUND-014`).

**This is not a live application.** Do not run it, do not extend it, do not treat its `src/content/*.json` files as anything other than seed/fixture data (already copied to `packages/testing/fixtures/content/` for that purpose). Once `FOUND-020` completes and the real storefront reaches parity, this directory should be deleted (per `docs/architecture/TARGET_REPOSITORY_STRUCTURE.md` §6 Step 6) — it is kept now only so nothing from the prior work is lost in the transition.

See `docs/architecture/GAP_ANALYSIS.md` for the item-by-item reuse/refactor/obsolete classification of everything in this folder.
